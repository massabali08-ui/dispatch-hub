# Al Fakhri Dispatch & Driver Report Manager

Offline dispatch table builder, driver directory, truck plate selector, and Excel/email report generator.

## How to Host for Free on GitHub Pages (Takes 2 Minutes)

1. Create a new repository on GitHub:
   - Go to [https://github.com/new](https://github.com/new)
   - Repository name: `dispatch-hub` (or any name you choose)
   - Set to **Public**
   - Click **Create repository**

2. Upload all the files from this folder:
   - Click **Add file** -> **Upload files**
   - Drag and drop all the files from this ZIP folder (`index.html`, `assets/`, `manifest.webmanifest`, `sw.js`, `.nojekyll`)
   - Click **Commit changes**

3. Turn on GitHub Pages:
   - Go to repository **Settings** -> **Pages** (in left sidebar)
   - Under **Build and deployment** > **Branch**: select `main` and `/ (root)`
   - Click **Save**

4. Your website will be live at:
   `https://<your-github-username>.github.io/dispatch-hub/`

## How to Use Offline Without Internet or AI Studio

- Once opened, the app caches itself automatically via Service Worker (PWA).
- You can click **"Install App"** in Chrome, Edge, or Android to install it on your computer/phone.
- On iPhone/iPad: Tap Share -> **Add to Home Screen**.
- It opens in its own window like native software and works without any internet connection!
